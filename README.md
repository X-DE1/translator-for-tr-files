# Translator for `.tr` Files

Translates .tr files used in [Luanti](https://www.luanti.org) with [Google Translate](https://translate.google.com)

## Usage

Open translator-for-tr-files.html in any web browser that supports JavaScript like Google Chrome, Firefox, Safari, and Microsoft Edge
